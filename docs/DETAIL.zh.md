# 快速刷新与重启

给插件开发用的 DeepSeek Harness 插件包：改完插件不用再手动退出、重新打开。

## 加了什么

会话标题栏**右上角**、`…` 菜单左边，常驻两个 28px 圆形图标：

- **重启**（电源符号：不封闭圆 + 中间竖短线）：Host 关闭桌面应用并用原命令行重新打开，
  Host 插件改动随之生效。
- **刷新**（圆形箭头）：`window.location.reload()`，让 Client 插件改动立即生效，不关窗口。

两个都是普通注册，没有装饰层；鼠标悬停有底色和说明文字。重启会中断正在运行的对话，
窗口关闭几秒后自动重开，失败原因显示在右下角提示里，而不是一直停在「重启中」。

## 行为与限制

- 仅支持 Windows 桌面版。重启走只监听本机的 HTTP 路由，辅助脚本是同目录的
  `restart.ps1`。
- Host 特意通过 WMI 服务启动辅助脚本：DSH 结束时会连带结束自己派生的进程，
  助手必须先于旧实例退出而存活。
- 重启脚本先请求外壳优雅退出（会话结束 + 关闭窗口）；7 秒后仍未退出则结束进程，
  Host 会在 IPC 断开时照常优雅收尾；随后等 Host 退出，再用原命令行启动应用。
- Client 会向 Host 追问这次重启的结果：脚本没启动起来会显示失败，而不是一直「重启中」。
- 刷新只让 Client 插件改动生效，未发送的输入会丢失；`app.asar` 里的内置
  `@deepseek-ai/*` 插件只能靠重启。

## 日志

`%TEMP%\dsh-quick-restart\restart-<时间戳>-<pid>.log`，保留 7 天。

## 安装

```sh
dsh plugin --profile <profile> add @iridensity_gray/dsh-quick-restart
```

无需配置。安装后需要重启一次桌面应用，Host 行和标题栏控件才会注册。
